# Yuanjing Zhao — Research Portfolio

Website: https://isoching.github.io/yuanjing-zhao-portfolio/

CV: https://isoching.github.io/yuanjing-zhao-portfolio/assets/YZ_CV.pdf

A static research portfolio built with HTML, CSS and JavaScript. Personal-profile information and all 11 publication/manuscript records follow the [University of Surrey profile](https://www.surrey.ac.uk/people/yuanjing-jason-zhao), captured on 26 October 2026 at the author’s request. It includes professional accounts, qualifications, memberships, teaching, SDGs and public contact details. Publication and review status follow that source.

The portrait and CV are the original files supplied by Yuanjing Zhao. The seven SDG images are the same original image assets displayed on the Surrey profile, arranged in a centered four-plus-three layout on desktop. Body text uses a larger scale and stronger contrast.

The interactive molecule and process pathways are illustrative. All 91 optimisation designs use synthetic data, not research results. TOPSIS runs in the browser on that fixed example dataset.

## Interactive systems vision

The author-provided green methanol systems figure is displayed near the top of the homepage. An HTML/SVG layer adds animated power, carbon and hydrogen connections, renewable-energy pulses and an AI-control indicator. All 13 modules have brief English explanations through pointer hover, keyboard focus or module selection. Motion can be paused and follows reduced-motion preferences. Mobile visitors can pan the image or use the module buttons. The reference DOI is [10.1016/j.ccst.2026.100603](https://doi.org/10.1016/j.ccst.2026.100603).

## Ocean and wind motion

The original interactive methanol molecule remains in the homepage hero, with its original renderer, drag/keyboard controls and independent pause button. The systems illustration now includes five clockwise rotating wind-turbine rotors, animated ocean swell and coastal foam. Its existing pause button controls these effects together with the animated connections. Reduced-motion preferences are respected. A generated clean background plate is visible only through local masks over the original stationary turbine blades; the author-provided original figure remains the base image.

## Deployment

GitHub Pages publishes the `main` branch, `/ (root)`. No build step is required. Push changes to update the website. The demo retains `noindex,nofollow` and a disallow-all `robots.txt`; direct public links remain accessible.

Only website files and the author-provided public CV/photo are published. Local source snapshots, reference notes, test reports and preview screenshots are excluded.
