# Yuanjing Zhao — Research Portfolio Demo

Website: https://isoching.github.io/yuanjing-zhao-portfolio/

A static, browser-side research portfolio built with HTML, CSS and JavaScript. Open `index.html` locally, or visit the GitHub Pages website. No build step is required.

The interactive molecule and process pathways are illustrative. All 91 design points use synthetic data, not research results. TOPSIS runs in the browser on that fixed example dataset.

## Deployment

GitHub Pages publishes the `main` branch, `/ (root)`. The `.nojekyll` file disables Jekyll processing. Push changes to update the website. Demo pages retain `noindex,nofollow` and a disallow-all `robots.txt`; the public URL can still be shared directly.

Only website files are published in this repository.
