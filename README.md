# Yuanjing Zhao — Research Portfolio

Website: https://isoching.github.io/yuanjing-zhao-portfolio/

A static research portfolio built with HTML, CSS and JavaScript. Personal-profile information and all 11 publication/manuscript records are transcribed from the [University of Surrey profile](https://www.surrey.ac.uk/people/yuanjing-jason-zhao), captured on 26 October 2026 at the author’s request. Includes the linked LinkedIn, ResearchGate, ORCID, Google Scholar and Wix portfolio; biography, qualifications, memberships, departments, teaching, SDGs and public contact details. The profile photo comes from the same source.

Publication and review status follow the source page. Under-review manuscripts are not presented as accepted publications. The source biography and dated qualifications contain different MSc years; both records are retained with an explanatory source note.

The interactive molecule and process pathways are illustrative. All 91 optimisation designs use synthetic data, not research results. TOPSIS runs in the browser on that fixed example dataset.

## Deployment

GitHub Pages publishes the `main` branch, `/ (root)`. No build step is required. Push changes to update the website. The demo retains `noindex,nofollow` and a disallow-all `robots.txt`; the public URL can still be shared directly.

Only website files are published. Local source snapshots, reference notes, test reports and preview screenshots are excluded.
